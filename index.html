런런런 계정 삭제

계정 및 관련 데이터 삭제 요청

이 페이지는 모바일 앱 런런런 사용자가 계정과 관련 데이터를 삭제 요청하는 방법을 안내합니다. 런런런은 현실 기반 러닝, 지도 기반 영토 점령, 친구/크루 경쟁 기능을 제공하는 앱입니다.

앱에서 계정 삭제하기

  1. 런런런 앱을 실행합니다.
  2. 로그인 후 하단 탭에서 프로필 또는 설정으로 이동합니다.
  3. 계정 카테고리를 엽니다.
  4. 탈퇴 또는 계정 삭제를 선택합니다.
  5. 안내 내용을 확인한 뒤 삭제 요청을 완료합니다.

웹에서 계정 삭제 요청하기

앱에 로그인할 수 없거나 앱을 다시 설치하지 않고 삭제를 요청하려면 아래 이메일로 요청해 주세요.

privacy@runrunrun.app

요청 시 본인 확인을 위해 런런런 계정 이메일과 닉네임을 함께 적어 주세요.

삭제되는 데이터

데이터 유형 처리 방식
계정 정보 이메일, 닉네임, 프로필 이미지, 소셜 로그인 연결 정보가 삭제됩니다.
러닝 기록 러닝 세션, GPS 경로, 거리, 시간, 페이스, 칼로리, 점령 기록이 삭제되거나 개인 식별이 불가능하게 처리됩니다.
소셜 데이터 친구 관계, 크루 가입 정보, 초대/가입 요청, 채팅 메시지, 알림 기록이 삭제됩니다.
게임 데이터 XP, 레벨, 배지, 랭킹, 점령 점수, 방어력 데이터가 삭제되거나 익명화됩니다.
기기 데이터 푸시 토큰, 앱 버전, 기기 정보, 워치/건강 연동 데이터가 삭제됩니다.

일부 보관될 수 있는 데이터

법령 준수, 보안, 부정 이용 방지, 분쟁 대응을 위해 필요한 최소 정보는 아래 기간 동안 보관될 수 있습니다.

  • 고객센터 문의 기록: 처리 완료 후 최대 3년
  • 부정 이용 탐지 및 보안 로그: 생성일로부터 최대 1년
  • 접속 및 오류 로그: 생성일로부터 최대 3개월
  • 관계 법령상 보관 의무가 있는 정보: 해당 법령에서 정한 기간

처리 기간

계정 삭제 요청은 본인 확인 후 최대 30일 이내 처리됩니다. 처리 결과는 요청에 사용한 이메일로 안내됩니다.
